================================================================================
3.7 BOOT SELECT
================================================================================
Jumper J3 is used to strap the MAX 10 FPGA device's BOOT_SEL pin. The 10M08
device supports holding two FPGA images in its Configuration Flash Memory.
The BOOT_SEL pin can be used to allow the user to select which image is
loaded by default on power up.
